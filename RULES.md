## Assumptions Phase 0 operated under

Each of these is the restrictive reading. If the actual rules are more
permissive, relax them deliberately and record the change here, rather than
letting the practice drift.

1. **Input data may not be redistributed or published.** `.gitignore` and the
   pre-commit hook enforce this mechanically.
2. **Patient genomic data may not enter a hosted LLM API.** Enforced as rule 1
   of `CLAUDE.md`. The clinical phenotype document is a documented exception,
   reasoned in `ETHICS.md` section 3.
3. **External API calls must not carry patient information.** Phase 0 made two
   calls, both to Ensembl REST, both carrying only public gene symbols.
4. **Outputs are CC BY 4.0**, per the challenge description.
5. **Moving the data between machines the team controls is permitted**; putting
   it on third-party cloud storage is not. This assumption is load-bearing for
   the alignment step and should be confirmed first.
